A fast drop-in for csv-reader 1.0.0: reads broken CSV files exactly as the reference does — stray CRs, unterminated quotes, junk after closing quotes, short and long rows — but several times faster. One left-to-right pass with native indexOf/slice doing the scanning: unquoted fields are sliced out whole, quoted fields are found by an indexOf walk that skips doubled quotes, and only fields that hold a stray CR, a quote, or junk fall back to a character loop. Deterministic, dependency-free, stdlib only.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
